# English Stories

A collection of short stories for English learners, organized by CEFR level.

## Levels

| Level | Description |
|-------|-------------|
| [A1](./A1) | Beginner |
| [A2](./A2) | Elementary |
| [B1](./B1) | Intermediate |
| [B2](./B2) | Upper Intermediate |
| [C1](./C1) | Advanced |
| [C2](./C2) | Proficiency |

Each level has its own directory containing stories written for that level.
